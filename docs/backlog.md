# Backlog

Every defect (`DEF-`) and gap (`TODO-`) recorded across the specification suite, in one
prioritised register. Each entry is issue-ready: it names the owning spec, and the spec's
§14 carries the full evidence, impact and proposed fix.

**This file and the specs must stay in parity.** Adding a `DEF-`/`TODO-` to a spec means
adding a row here in the same change, and vice versa — see
[\_conventions/authoring-guide.md](./_conventions/authoring-guide.md).
